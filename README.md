# ASCII 七並べ － あなた VS CPU 3人

## ゲームの概要

トランプゲーム「七並べ」を、ターミナル上で遊べるようにPythonで作成したゲームです。

プレイヤー1人とCPU3人の合計4人で対戦します。場に出ているカードにつながる数字のカードを順番に出し、最初に手札をすべてなくしたプレイヤーが勝利します。

## 動作環境

- OS：macOS
- Python：3.14.8
- 使用ライブラリ：Python標準ライブラリ

## インストール方法

1. GitHubからリポジトリをダウンロード、またはクローンします。
2. ダウンロードしたプロジェクトのフォルダを開きます。
3. Python 3をインストールしていることを確認します。

## 起動方法

ターミナルでプロジェクトのフォルダに移動し、次のコマンドを実行します。

```bash
python3 w14_ascii_seven_cards.py
```

## 操作方法

- `S`：スペード
- `H`：ハート
- `D`：ダイヤ
- `C`：クラブ

カードはマークと数字を組み合わせて入力します。

入力例：
- `S6`
- `H10`
- `DA`

その他の操作：
- `P`：パス
- `Q`：ゲームを終了

## 追加・改良した機能

### 1. CPUのカード選択機能

CPUが手札の中から場に出せるカードを選び、自動でカードを出すようにしました。

### 2. パス回数の制限

パスできる回数を最大3回に設定しました。3回目のパスをすると負けになります。

### 3. ゲーム結果の統計表示

ゲーム終了時に、勝敗や合計ターン数、プレイヤーの手札枚数、パス回数などを確認できるようにしました。
